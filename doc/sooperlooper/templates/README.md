# Autonomous governance templates

Use these templates only for human-facing coordination that cannot be represented
by the normal pull-request and checkpoint contracts.

- `HUMAN-DECISION.md` — one bounded L3/L4 decision with options, senior
  recommendation and exact blocked state.
- `AUTONOMOUS-REPORT.md` — sparse progress, blocker or milestone report for a
  long-running Hermes mission.

Repository checkpoints remain the durable handoff. These templates do not
replace `CHECKPOINTS.md`, `CURRENT.md`, `WORK-QUEUE.md` or the active PR.
